About the Game

  • The game starts out with a simple game of monopoly, but soon you will discover that there is much more to it.
  • You will be able to add new fields to the board, and discover new mechanics and features.
  • There are multiple types of fields, and not all of them are just for earning money.
  • You will be able to play on multiple boards, each with its own set of fields and mechanics.
  • The game includes systems for researching, pets, an inventory, and even two rebirth layers.
  • But that's not all, you will also discover multiple sub-games, tightly integrated into the progression.
  • These sub-games include a tower defense, an incremental, and a dungeon crawler.
  • The game is highly modular and expandable with a content pack system, which allows you to write your own json files and load them into the game.
  • This system will allow you to easily add new items, cards, fields, and much more.
  • Please note that this game is still in development, and I plan on adding more content and functionality, as well as rebalancing and fixing bugs.
